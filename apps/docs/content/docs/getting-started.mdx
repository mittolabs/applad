---

## Run the stack

```bash
git clone https://github.com/mittolabs/applad
cd applad
docker compose up -d
```

That starts PostgreSQL, Redis, the API, the background workers and the admin console.

## Open the console

Visit **`console.applad.io.localhost`** and create your first admin account. From there you can
create a project, generate an API key, and start using the services.

<Callout title="Who else can sign up">
  A self-hosted Applad closes registration behind that first account, so your
  instance is not left open to the internet. To add colleagues, invite them
  from the organization's Members tab and send them the link you are shown:
  it creates their account and adds them to the organization, without
  reopening registration. Set `CONSOLE_SIGNUP_ENABLED=true` to leave
  registration open to anyone, or `false` to close it entirely.
</Callout>

## Connect your app

Install a client SDK and point it at your project:

```ts
import { Applad } from '@mittolabs/applad';

const applad = new Applad({
  endpoint: 'http://api.applad.io.localhost',
  projectId: 'YOUR_PROJECT_ID',
});
```

<Callout type="info">
  Server SDKs (Node, Go, Python) authenticate with a project API key created in the console
  under **Settings → API keys**.
</Callout>
