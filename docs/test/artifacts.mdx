---
title: Artifacts
description: "The runner's artifactsPath directory is copied out of the container after a run and stored, with recordings attached to the case that produced them."
---

If your runner names an `artifactsPath`, that directory is copied out of the
container after the run and stored as artifacts. Where a runner names its output
after the test (as Playwright does), the artifact is attached to that case, so a
failing browser test shows its own recording.

```bash
curl https://api.applad.io/v1/tests/runs/<runId>/artifacts -H "x-applad-key: <apiKey>"
```

Each artifact has a `kind` (`video`, `screenshot`, `trace`, `report`, or
`other`), inferred from the file extension. Videos are listed first. Open one
directly; it is served as a file (with range requests, so a video seeks):

```bash
curl https://api.applad.io/v1/tests/artifacts/<artifactId> -H "x-applad-key: <apiKey>"
```
