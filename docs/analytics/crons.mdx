A cron monitor watches a scheduled job by having the job check in when it runs.
Create the monitor with the schedule it should keep, then have the job POST a
check-in at the end of each run:

```bash
# define the monitor
curl -X POST "$APPLAD/v1/analytics/crons" \
  -H "x-applad-project: $PROJECT" -H "x-applad-key: $KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"nightly-report","schedule":"0 2 * * *","timezone":"UTC","gracePeriod":5}'

# the job checks in
curl -X POST "$APPLAD/v1/analytics/crons/<monitorId>/checkin" \
  -H "x-applad-project: $PROJECT" -H "x-applad-key: $KEY" \
  -H "Content-Type: application/json" \
  -d '{"status":"ok","durationMs":8200}'
```

Each check-in records status, duration, and history, and updates the monitor's
`lastRunAt`. Monitors can be toggled (`PATCH .../toggle`) and deleted.

<Callout title="Check-ins are recorded, not yet policed">
Check-ins and their history are stored, and a monitor carries a `gracePeriod`.
Automatic detection of a missed run (marking a monitor failed when a check-in
does not arrive in time) is not wired up in this build, so treat cron
monitoring as a check-in log for now.
</Callout>
