This guide takes you from nothing to reading and writing data through an SDK. It
assumes you have an Applad instance to talk to. If you do not, bring one up first
with [Self-hosting](/self-hosting) (a one-line installer), or use a hosted
instance.

![The Applad console sign-in screen](/screens/login.png)
_You manage everything from the console. Sign in, or create the owner account on a fresh self-hosted instance._

<Steps>

<Step>

### Create a project

Open the admin console and sign in (on a fresh self-hosted instance the first
account you create becomes the owner). Then create an **organization**, create a
**project** inside it, and copy the project's **ID** from its settings.

A project is an isolated backend with its own database, users, and API keys.

![The console projects page, showing an organization and its projects](/screens/projects.png)
_Projects live inside an organization. Each one is an isolated backend._

<Callout title="Client keys vs server keys">
  Client SDKs need only the project ID: they act as the signed-in user, and
  [permissions](/build/permissions) decide what that user can do. Server SDKs also
  need an **API key** (under the project's Settings), which acts with full access
  for trusted backend work.
</Callout>

</Step>

<Step>

### Connect an SDK

Install a client SDK and point it at your instance and project.

<Callout title="Set endpoint to your own instance">
  The examples below show `https://api.applad.io`, which is Applad Cloud. On a
  self-hosted instance, `endpoint` is your own origin, and the SDK appends `/v1`
  for you. Use `https://yourdomain` for a domain install, or `http://localhost`
  for a bare local install (the installer's default). Do not include `/v1` in the
  value.
</Callout>

<Tabs items={['JavaScript', 'Dart']}>
  <Tab value="JavaScript">
    ```bash
    npm install @mittolabs/applad
    ```

    ```ts
    import { Applad } from '@mittolabs/applad';

    const applad = new Applad({
      endpoint: 'https://api.applad.io', // your instance's API base
      projectId: 'YOUR_PROJECT_ID',
    });
    ```
  </Tab>
  <Tab value="Dart">
    Add `applad` to your `pubspec.yaml`, then:

    ```dart
    import 'package:applad/applad.dart';

    final applad = Applad(
      endpoint: 'https://api.applad.io',
      projectId: 'YOUR_PROJECT_ID',
    );
    ```
  </Tab>
</Tabs>

There are SDKs for [JavaScript, Dart, Node, Go and Python](/sdks).

![The project settings page with API keys](/screens/settings.png)
_Server SDKs authenticate with an API key, created and revoked under the project's Settings._

</Step>

<Step>

### Sign a user in

Create an account and open a session. The session is what makes the following
requests act as that user.

<Tabs items={['JavaScript', 'Dart']}>
  <Tab value="JavaScript">
    ```ts
    await applad.auth.createAccount('ada@example.com', 'a-strong-password', { name: 'Ada' });
    const session = await applad.auth.createEmailSession('ada@example.com', 'a-strong-password');
    applad.setJWT(session.secret); // authenticate subsequent requests as this user
    ```
  </Tab>
  <Tab value="Dart">
    ```dart
    await applad.auth.createAccount(email: 'ada@example.com', password: 'a-strong-password', name: 'Ada');
    await applad.auth.createEmailSession(email: 'ada@example.com', password: 'a-strong-password');
    // the Dart SDK applies the session token for you
    ```
  </Tab>
</Tabs>

See [Authentication](/build/authentication) for OAuth, MFA, magic links, and more.

</Step>

<Step>

### Store and read data

Create a table (once, from the console or a setup script) and start writing rows.
A row can carry its own [permissions](/build/permissions) so only the right people
can read it.

<Tabs items={['Dart', 'JavaScript']}>
  <Tab value="Dart">
    ```dart
    // Create a row
    final row = await applad.databases.createRow(
      databaseId: 'app',
      tableId: 'messages',
      data: {'body': 'Hello, Applad'},
    );

    // Query rows
    final result = await applad.databases
        .from('app', 'messages')
        .orderDesc('created_at')
        .limit(20)
        .get();

    for (final r in result.rows) {
      print(r['body']);
    }
    ```
  </Tab>
  <Tab value="JavaScript">
    ```ts
    // Create a row
    const row = await applad.databases.createRow('app', 'messages', { body: 'Hello, Applad' });

    // Query rows
    const result = await applad.databases
      .from('app', 'messages')
      .orderDesc('created_at')
      .limit(20)
      .get();

    for (const r of result.rows) console.log(r.body);
    ```
  </Tab>
</Tabs>

</Step>

## Server SDKs: the first backend call

The steps above use a **client SDK**, which acts as the signed-in user. On a
trusted backend you instead use a **server SDK**, which authenticates with an
**API key** (`x-applad-key`) and has full, permission-bypassing access. Use it
to provision users, run admin jobs, and react to webhooks. Never ship an API key
to a client.

<Callout title="Same endpoint rule">
  As above, `endpoint` is your instance origin **without** `/v1`. On Applad
  Cloud that is `https://api.applad.io`; on a self-hosted instance it is your own
  origin. Create the API key under the project's **Settings**, and keep it in an
  environment variable or secret store.
</Callout>

Construct the server client, provision a user, then write and read a row.

<Tabs items={['Node.js', 'Go', 'Python']}>
  <Tab value="Node.js">
    ```bash
    npm install @mittolabs/applad-node
    ```

    ```ts
    import { ApplAdServer } from '@mittolabs/applad-node';

    const server = new ApplAdServer({
      endpoint: 'https://api.applad.io', // your instance origin
      projectId: 'YOUR_PROJECT_ID',
      apiKey: process.env.APPLAD_API_KEY!,
    });

    // Provision a user from your backend.
    const user = await server.users.createUser('ada@example.com', 'a-strong-password', {
      name: 'Ada Lovelace',
    });

    // Write a row.
    const row = await server.databases.createRow('app', 'messages', { body: 'Hello, Applad' });

    // Read rows back with the fluent query builder.
    const result = await server.databases
      .from('app', 'messages')
      .orderDesc('created_at')
      .limit(20)
      .get();

    for (const r of result.rows) console.log(r.body);
    ```
  </Tab>
  <Tab value="Go">
    ```bash
    go get github.com/mittolabs/applad-go
    ```

    ```go
    package main

    import (
    	"fmt"
    	"log"

    	applad "github.com/mittolabs/applad-go"
    )

    func main() {
    	client := applad.New("https://api.applad.io", "YOUR_PROJECT_ID", "YOUR_API_KEY")

    	// Provision a user from your backend.
    	user, err := client.Users().CreateUser("ada@example.com", "a-strong-password", "Ada Lovelace")
    	if err != nil {
    		log.Fatal(err)
    	}
    	fmt.Println(user["id"])

    	// Write a row.
    	_, err = client.Databases().CreateRow("app", "messages", map[string]interface{}{
    		"body": "Hello, Applad",
    	})
    	if err != nil {
    		log.Fatal(err)
    	}

    	// Read rows back with the fluent query builder.
    	result, err := client.Databases().From("app", "messages").
    		OrderDesc("created_at").
    		Limit(20).
    		Get()
    	if err != nil {
    		log.Fatal(err)
    	}
    	for _, r := range result.Rows {
    		fmt.Println(r["body"])
    	}
    }
    ```
  </Tab>
  <Tab value="Python">
    ```bash
    pip install applad
    ```

    ```python
    from applad import Client

    client = Client("https://api.applad.io", "YOUR_PROJECT_ID", "YOUR_API_KEY")

    # Provision a user from your backend.
    user = client.users.create_user("ada@example.com", "a-strong-password", name="Ada Lovelace")
    print(user["id"])

    # Write a row.
    client.databases.create_row("app", "messages", {"body": "Hello, Applad"})

    # Read rows back with the fluent query builder.
    result = client.databases \
        .from_table("app", "messages") \
        .order_desc("created_at") \
        .limit(20) \
        .get()

    for r in result.rows:
        print(r["body"])
    ```
  </Tab>
</Tabs>
