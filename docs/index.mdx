Applad is a complete, AI-native development infrastructure for your apps. You
plan, build, test, deploy and monitor in one platform, so you ship features
instead of building and running plumbing. Authentication, a database with
fine-grained permissions, file storage, serverless functions, messaging and
realtime updates all sit behind **one `/v1` API** with SDKs for JavaScript,
Dart, Node, Go and Python.

It is open source. Run it yourself, own your data, with no per-seat pricing or
vendor lock-in, or let Applad Cloud run it for you.

## How it fits together

You create a **project** (an isolated backend with its own database, users, and
API keys). Your app talks to it two ways:

- **Client SDKs** run in your app and act as the **signed-in user**. Requests
  carry the user's session, and [permissions](/build/permissions) decide what
  they can see and do.
- **Server SDKs** run on your own backend and act with an **API key** that has
  full access, for trusted server-side work.

Once you have learned one service, the rest follow. Head to
[Get started](/getting-started), or pick up the [SDKs](/sdks).
