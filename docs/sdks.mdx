---

Applad ships five SDKs that all speak the same `/v1` API.

| SDK | Package | Use |
| --- | --- | --- |
| JavaScript (client) | `@mittolabs/applad` | Browser / mobile apps |
| Node (server) | `@mittolabs/applad-node` | Backend services |
| Dart | `applad` | Flutter apps |
| Go | `github.com/mittolabs/applad-go` | Go services |
| Python | `applad` | Python services |

## Install

```bash
# JavaScript / client
npm install @mittolabs/applad

# Node / server
npm install @mittolabs/applad-node

# Python
pip install applad

# Go
go get github.com/mittolabs/applad-go
```
